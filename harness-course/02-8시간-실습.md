→ **학생이 직접 고른다** (예: "메모 객체 안에 tags 배열")

## 블록 5. TDD — 이슈 #1 (105분, 중간 10분 휴식)

### 목표
**시험 문제 먼저 → 통과 → 정리** 한 바퀴를 손으로 돌리고, 각 단계를 스킬로 만들기

> 📌 진행 방식: 각 단계에서 **① 먼저 스킬을 만들고 ② 바로 실행**합니다. 다음 블록에서 재사용하기 위해서예요.

```bash
git checkout -b feat/tag-1
```

### 5-1. 시험 범위 정하기: /test-scenarios (20분)
```
.claude/skills/test-scenarios/SKILL.md 스킬을 만들어줘. 이슈 번호를 인자로 받는다.
절차:
1. gh issue view <번호> 로 이슈와 완료 체크리스트 읽기
2. 함수 시그니처(입력/출력/에러 메시지)를 제안 → 사용자 승인 받기. 구현 금지
3. 테스트 시나리오를 [정상] [경계] [예외] 로 분류해서 제안
   형식: "함수명 should ... when ..."
   경계값은 최대-1, 최대, 최대+1 을 꼭 포함
4. 완료 체크리스트 항목이 전부 시나리오에 들어갔는지 대조표 → 사용자 승인
5. 결과를 docs/features/tag/scenarios-<번호>.md 에 저장
```
```
/test-scenarios 1
```
💬 **질문 던지기**: "태그 최대 5개면 경계 시나리오는 몇 개, 어떤 숫자로?"
